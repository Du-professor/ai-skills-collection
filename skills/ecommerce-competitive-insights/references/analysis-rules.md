# 分析与推断规则

## 价格

- 按币种分别计算价格最小值、中位数、最大值和品牌中位价格。
- 相对价差以同币种整体中位价格为基准。
- 单次快照不产生趋势结论。
- 同一商品至少有两个不同日期的有效价格时，才计算首末价格差和变化率。
- 缺失价格、标价、评分或评论量显示未知，不做插值。

## 评论聚合

- 评论标注先通过ID、哈希、证据片段和枚举值校验。
- 主题提及数、情感比例、商品覆盖数和覆盖率全部由脚本计算。
- 分母是该维度有效标注数，不包含未知情感。
- 报告同时展示评论总量、抽样分析量及覆盖率。
- 不允许模型自行换算百分比或改写排名。

机会指数仅用于同一分析内排序：

`机会指数 = 2 × 负向提及 + 混合提及 + 严重度权重和 + 商品覆盖数`

严重度权重：高=3、中=2、低=1、未知=0。该指数不是市场规模、销量或需求强度。

## 证据层级

- `fact`：原始字段和原文证据。
- `derived`：可重算的脚本指标。
- `inference`：对事实和指标的解释，必须携带 `basis` 与
  `confidence`（高/中/低）。
- `unknown`：输入缺失或证据不足。

## 建议边界

允许形成产品、定价、定位和内容建议，但必须引用相应价格指标或评论维度。不得声称市场份额、销量、趋势、因果关系或用户人口属性，除非输入直接提供且证据账本记录来源。
