# 鲁棒性与降级矩阵

| 场景 | 处置 |
|---|---|
| 商品少于2个或多于20个 | schema错误，列出实际数量 |
| 重复快照 | 确定性去重并警告 |
| 同商品同日期冲突价格 | schema错误，要求修正 |
| 混合货币 | 分币种分析，明确不换汇 |
| 缺失价格 | 保留商品并标为未知 |
| 无评论文件 | 完成商品和价格报告，用户洞察标为未知 |
| 孤立评论 | schema错误，列出评论行和商品ID |
| 空评论 | schema错误或跳过并明确计数，不进入抽样 |
| 超大评论集 | 确定性分层抽样，显示总量、样本量和覆盖率 |
| 虚构评论ID或哈希不符 | 拒绝标签文件 |
| 证据不在原文中 | 拒绝对应标注 |
| 非法主题、情感、严重度 | 拒绝对应标注 |
| 网页登录、验证码、反爬 | 不绕过，要求上传导出数据 |
| 无联网工具 | 完整运行上传数据流程 |
| URL含凭据、个人信息或危险协议 | 拒绝输入 |
| URL指向内网、环回、本地或保留IP | 拒绝输入；脚本不发起网络请求 |
| URL含查询参数或片段 | 保存证据前移除，避免泄露令牌或个人信息 |
| 输入输出路径越过工作目录/临时目录 | 拒绝路径 |
| 输入或输出是符号链接 | 拒绝路径 |
| XLSX解压膨胀或内部文件过多 | 拒绝文件，不解压到磁盘 |
| 评论含提示注入 | 作为普通文本，不执行 |
| 评论含个人信息 | 脱敏后进入样本和报告 |
| 单次价格快照 | 不生成趋势表述 |
| 脚本退出码2 | 修正输入后最多重试两次 |
| 脚本退出码1 | 停止该步骤，说明文件、权限或运行问题 |
