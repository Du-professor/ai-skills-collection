# 行程单样例（用户输入 → 成品）

## 用户输入

> 帮我规划杭州 3 日亲子游，从上海出发，8 月初，预算 5000，爱吃但不要吃辣。

## 助手处理流程（对应 SKILL.md 9 步）

1. 读取 `references/` 全部规则。
2. `--read` 长期偏好：返回空档案（首次使用）→ 默认值按输入。
3. 一次性确认：目的地/日期已给，无需追问。
4. 高德地图 MCP 判定：假设可用 → `data_source_note=realtime`，部分提醒（灵隐寺）因工具未覆盖降级为 `estimate`。
5. 生成行程 JSON（枚举取自 rubric，无评分）：交通高铁往返、住宿西湖民宿、景点按 自然/亲子/历史/美食 组合。
6. `validate_itinerary.py` 校验通过（exit 0），预算 2255 ≤ 5000，无重叠。
7. `--merge` 写入偏好：预算档位 comfort、忌口不吃辣、兴趣 亲子/美食/自然、同行 家庭、目的地 杭州。
8. `render_itinerary.py` 生成 `itinerary.html`。
9. 交付 HTML 行程单并附「已按您的长期偏好个性化」。

## 成品行程单要点

- **时间轴**：Day1 高铁→西湖→午餐→少儿公园→民宿；Day2 早餐→灵隐寺→素斋→浙博→散步；Day3 早餐→河坊街→小吃→高铁返程。
- **天气路况**：顶部「✅ 已接入高德地图实时数据」；Day2 灵隐寺标注「估算：周末易拥堵，建议早到」+ 高德查看提示。
- **预算摘要**：交通 240 / 住宿 800 / 门票 135 / 餐饮 460 / 备用 620 / 合计 2255（预算 5000）。
- **偏好标签**：budget_tier=comfort、dietary=不吃辣、interest=亲子、companion=家庭。
- **强制声明**：免责声明 + 隐私说明（HTML 底部）。

## 不可用高德时的差异

若高德地图 MCP 未连接，顶部改为「⚠️ 数据基于知识库估算，非实时…」，所有提醒标 `estimate` 并附高德查看提示；行程主体不变。
