# 行程规则手册（Itinerary Rubric）

> 本文件是**枚举、预算公式、兴趣映射的唯一来源**。模型打标签、脚本校验（`scripts/validate_itinerary.py`）、渲染（`scripts/render_itinerary.py`）都必须引用本文件中的值，**禁止自创枚举或比例**。脚本内常量须与本文件保持一致，改动时同步更新。

---

## 1. 交通方式枚举（transport_mode）

| 枚举值 | 适用场景建议 |
|---|---|
| `飞机` | 远距离城际（>1000km 或时间敏感） |
| `高铁` | 中远距离城际（200–1500km，性价比高） |
| `自驾` | 周边游、多景点环线、行李多 |
| `公交地铁` | 市内通勤、景点间接驳 |
| `打车` | 市内短驳、赶时间、携带老人/幼童 |
| `步行` | 景区内、老城区、1km 内接驳 |
| `骑行` | 骑行绿道、慢城、短途接驳 |
| `轮渡` | 滨水城市、岛屿接驳 |
| `长途大巴` | 无高铁覆盖的城际、预算敏感 |

## 2. 住宿类型枚举（accommodation_type）

| 枚举值 | 适用人群建议 |
|---|---|
| `经济连锁` | 单人/朋友穷游、商务短住 |
| `舒适商务` | 商务、情侣、家庭舒适型 |
| `豪华酒店` | 豪华档、度假、蜜月 |
| `民宿` | 家庭、亲子、文艺/在地体验 |
| `青年旅舍` | 单人/学生穷游、社交 |
| `服务公寓` | 家庭长住、带厨卫需求 |

## 3. 景点 / 活动分类枚举（category）

每个 `type=attraction` 的 segment **必须且只能**选一个 `category`：

`自然风光` · `历史古迹` · `博物馆` · `主题乐园` · `美食街区` · `购物中心` · `城市观景` · `演出演艺` · `户外探险` · `休闲度假` · `亲子乐园` · `宗教场所` · `市集` · `校园`

`早餐` · `午餐` · `晚餐` · `小吃夜市` · `下午茶` · `特色宴`

## 5. 预算分配公式（按预算档位 budget_tier）

每档为**分项金额占总预算的比例上限**（validate 仅对超上限给**警告**，不致命）；`备用金` 为**下限**。

| 档位 | 交通≤ | 住宿≤ | 门票≤ | 餐饮≤ | 备用≥ |
|---|---|---|---|---|---|
| `economy`（经济） | 35% | 20% | 15% | 25% | 10% |
| `comfort`（舒适） | 30% | 28% | 15% | 22% | 10% |
| `luxury`（豪华） | 25% | 35% | 15% | 20% | 10% |

**硬约束（validate 判 exit=2 的错误）**：
- `Σ 各分项金额 ≤ total_budget`（超支即错误）
- `Σ 分项合计 == budget_breakdown.total`（一致性错误）
- `备用金 ≥ total_budget × 10%` 为**警告**（stdout 提示；除非因此导致超总预算，否则不致命）
- 单类占比超上限为**警告**（不致命）

> 备注：自由活动段（`type=free`）不计成本，但时间段仍纳入时间冲突检查。

## 6. 兴趣标签 → 场景映射

模型依据用户 `interest_tags` 选择景点 `category` 与活动强度：

| 兴趣标签 | 优先 category |
|---|---|
| `美食` | 美食街区 / 特色宴 / 小吃夜市 |
| `自然` | 自然风光 / 户外探险 |
| `历史` | 历史古迹 / 博物馆 |
| `购物` | 购物中心 / 市集 |
| `亲子` | 亲子乐园 / 主题乐园 |
| `摄影` | 城市观景 / 自然风光 |
| `夜生活` | 演出演艺 / 小吃夜市 |
| `休闲` | 休闲度假 / 城市观景 |
| `文化` | 博物馆 / 宗教场所 / 演出演艺 |
| `冒险` | 户外探险 |

兴趣为空时：使用偏好档案标签；若无则默认 `城市观光 + 美食`。

## 7. 同行人类型 → 约束（companion_type）

枚举：`单人` · `情侣` · `家庭` · `朋友` · `商务`

- `家庭`：住宿优先 `民宿`/`服务公寓`；景点强度降档，避免高强度户外（标注「平缓步道/适合幼童」）；餐饮回避重辣/易过敏。
- `情侣`：可增加 `休闲度假`/`城市观景`；住宿优先 `舒适商务`/`豪华酒店`。
- `单人`：住宿可 `青年旅舍`/`经济连锁`；交通灵活。
- `朋友`：住宿可拼房；餐饮偏好 `小吃夜市`/`特色宴`。
- `商务`：住宿优先 `舒适商务`/`豪华酒店`；行程紧凑、留缓冲；减少高强度景点。

## 8. 通用强度建议

- 每位同行人每日景点段建议 ≤ 4 个，避免赶场。
- 含老人/幼童时，户外探险类强度标注「需评估体力」，并提供室内备选。
- 节假日/旺季：在 `weather_traffic_notes` 标注人流与价格预警。
