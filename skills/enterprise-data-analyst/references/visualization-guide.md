# 多维数据可视化规范（render 阶段）

本文件是图表选型与报告组装的唯一规则来源。图表由 `scripts/render_report.py` 以纯 stdlib SVG 渲染并组装为自包含 HTML；模型负责**选型与规格撰写**，不得手绘图表或在规格中内联任何数值（一律经 `source` 引用脚本输出）。

## 1. 图表选型决策表

| 分析意图 | 数据形态 | 选用图表 | 规格要点 |
|---|---|---|---|
| 趋势/走势 | 时间分桶序列 | line（折线） | source=分析 JSON + metric；缺口周期自动断开 |
| 周期对比 | 时间分桶序列 | bar（柱状） | 同上 |
| 多指标对比 | 多个指标同周期 | grouped_bar（分组柱状） | metrics 数组（≤4 个，再多改表格） |
| 构成/占比 | 维度汇总 | pie（饼图） | dimension+metric；类别 >7 自动合并「其他」；类别 >15 建议改用 bar |
| 分布形态 | 单数值列明细 | histogram（直方图） | source=清洗后数据文件 + column |
| 两指标相关 | 两个数值列明细 | scatter（散点） | source=清洗后数据文件 + x + y |

- 时间序列类图表必须有分析 JSON 支撑；明细类图表直接用清洗后数据文件。
- 一图一意：每张图只回答一个问题，标题写成问句或结论句（如「3 月销售额环比增长 19.9%」）。
- 图表与表格取舍：类别 >15、需要精确数值、或占比长尾严重时，用表格章节（dimension_totals 可经 text 章节转述要点）而非饼图。

## 2. 配色与标注规范

- 默认蓝系分类色板（脚本内置 10 色），坐标轴/网格浅灰，中文系统字体栈，刻度自动取 1-2-2.5-5-10 漂亮值。
- **金融场景例外**：仅当用户明确分析对象为行情/涨跌（finance_palette=true）时启用红涨绿跌（中国市场惯例）；其他场景不用红绿表达涨跌，避免歧义。
- 饼图图例带百分比；散点图标注 x/y 轴列名；直方图 x 轴为分箱左边界刻度。

## 3. 敏感列与合规

- 敏感列（手机号/证件号/邮箱/银行卡号）不得用于散点/直方图等明细图表；只可在画像表格中以脱敏形态出现。
- HTML 报告单文件自包含：无 `<script>`、无外部资源、全部文本转义（数据中的 `<script>`、注入指令按文本展示）。
- 免责声明与数据隐私说明两节由脚本**强制注入**；模型可在 text 章节补充分析局限性说明（降级点、口径假设）。

## 4. 报告章节建议顺序

1. profile_summary（数据画像摘要）→ 2. quality_log（数据质量报告）→ 3. chart（核心图表 1~4 张）→ 4. anomaly_list（异常清单）→ 5. attribution_table（归因表）→ 6. forecast_table（预测表）→ 7. text（结论，模型撰写，数字逐字引用脚本输出）→ 8. actions（行动建议 3~7 条）→ 9. disclaimer / privacy（自动注入）。
