# 鲁棒性案例清单（Robustness Cases）

本 Skill 须在所有下列异常输入/场景下**不崩溃、无格式错误、无逻辑错误**，给出明确、友好的处理。覆盖 ≥22 项，对应赛事"运行稳定性与鲁棒性 30 分"。

| # | 场景 | 期望行为 |
|---|---|---|
| 1 | 完全未提供原文 | 一次性提问补齐：要解读哪份政策、以什么方式提供 |
| 2 | 粘贴内容为空或纯空白/不可见字符 | 提示"未检测到有效文本"，不进入解析 |
| 3 | 内容明显非政策（小说/广告/乱码） | 提示"未识别到政策文本特征，请确认是否为政策原文" |
| 4 | 超长文档（>3 万字） | 分块处理或提示用户聚焦章节；不超时、不截断丢失结构 |
| 5 | 原文存在相互矛盾的条款 | 如实并列呈现矛盾点，不擅自择一；在报告中标注"原文表述存在差异" |
| 6 | 缺失关键字段（无发布日期/机关） | 对应字段写「未明确」，不编造 |
| 7 | compare 仅提供 1 份政策 | 提示"对比模式至少需要 2 份政策"，不强行输出 |
| 8 | compare 中某份政策内容为空 | 跳过该份并提示，或要求补齐 |
| 9 | 外文政策（英文/日文等正文） | 提示"本工具面向国内政策解读，请确认是否确需解读外文文本" |
| 10 | 境外机构/法案作为解读对象（如境外机关名、境外法） | 拒绝将其作为解读对象，提示仅面向国内政策 |
| 11 | 本地文件不存在 | 明确报错路径，提示检查路径或改用粘贴 |
| 12 | 本地文件无读取权限 | 提示权限问题，建议改用粘贴 |
| 13 | `.docx` 损坏/非标准 | 捕获异常，提示"文档解析失败，请粘贴正文" |
| 14 | `.docx` 为加密文档 | 提示"加密文档无法解析，请粘贴正文" |
| 15 | 用户提供 `.pdf` | 提示"暂不支持 PDF 自动解析，请复制正文粘贴" |
| 16 | 粘贴内容含 HTML/脚本标签 | 渲染时转义，绝不执行；摘要中保留为纯文本 |
| 17 | 用户追问超出原文范围 | 回答「原文未提及」，不猜测、不外推 |
| 18 | 模型编造条款编号/虚构引用（幻觉） | 校验阶段要求 `quote` 须为原文片段；发现虚构则重试并提示"请仅引用原文" |
| 19 | 模型未输出合法 JSON | 提示重输出；超过重试上限则降级给出人工指引 |
| 20 | 模型 JSON 缺必填字段 | `validate_policy.py` 输出字段级错误，重试 ≤2 |
| 21 | 枚举值非法（如未知 category） | 校验报错并重试 |
| 22 | qa 的 `answer` 为空 | 校验报错并重试 |
| 23 | 多次重试仍失败（>2 次） | 降级：输出已能确定的部分 + 明确的人工复核提示，不抛出未处理异常 |
| 24 | 运行环境无网络 | 脚本本就零网络，功能不受影响；提示"本工具无需联网" |
| 25 | 某政策无明确支持标准 | 对应字段写「未明确」，不臆测额度 |
| 26 | 同一政策被多次解读 | `policy_store.py` 去重/更新记录，不重复堆积 |

**实现要点：** 所有脚本的异常必须以 try/except 兜底并输出友好信息；模型输出先经 `validate_policy.py` 校验再渲染；任何不可信内容（原文、模型输出）在渲染前做 HTML 转义。
