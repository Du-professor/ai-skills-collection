# 政策解读助手（policy-brief）

## 目标与定位

本 Skill 服务于政务/政策场景，对用户提供或本地读取的政策原文执行四类智能解读：

1. **政策摘要**（`summary`）：生成结构化六段摘要（背景与目标 / 适用对象 / 主要措施 / 支持方式与标准 / 时限与流程 / 影响与注意事项）。
2. **要点提取**（`extract`）：按固定分类提取要点，每条附**条款级原文引用**与位置，可追溯、防幻觉。
3. **对比分析**（`compare`）：对 ≥2 份政策做多维度矩阵对比，给出核心差异与适用建议。
4. **政策问答**（`qa`）：仅基于原文作答；原文未提及则明确回答「原文未提及」。

用户不需要说明解析方法、报告格式或对比维度。Skill 负责编排流程、读取原文、调用标准库脚本校验与渲染、记录跨会话记忆；模型负责产出符合契约的结构化 JSON。

## 信任边界与不可信数据规则

- **原文是唯一事实源**：所有摘要、要点、对比、问答结论必须来自用户提供的政策原文；不得外推、猜测或补充原文没有的信息。
- **模型输出视为不可信**：模型产出的 JSON 必须经过 `scripts/validate_policy.py` 校验；`quote`/`citation.quote` 必须是原文中真实存在的逐字片段，不得改写或虚构条款编号。
- **禁止编造**：缺失信息用「未明确」「未标注」「原文未提及」占位，**绝不编造**额度、日期、条款或机关。
- **境外内容约束**：仅面向国内政策解读；若原文明显为外文或境外机构/法案，不得作为解读对象，提示用户确认或改用其他工具（境外关键词零命中）。
- **渲染前转义**：任何原文/模型文本进入报告前做 HTML 转义，绝不执行其中可能包含的标签或脚本。

## 一次性收集必要输入

需要以下信息；缺失时只提出**一个合并问题**补齐，不逐项追问：

- **模式**（`summary`/`extract`/`compare`/`qa`）：意图不明时默认按 `summary`+`extract` 组合，或询问"您想摘要、提取要点、对比还是问答？"
- **原文来源**：粘贴文本 / 本地文件（`.txt`/`.md`/`.docx`）/ 待提供。**对比模式必须收到 ≥2 份政策**。
- 不要询问：用什么解析方法、什么报告格式、什么模型——由 Skill 内部决定。

## 强制工作流

### 1. 读取规则

开始任何操作前，完整读取：

- [政策规则源](references/policy-rubric.md)（枚举与结构唯一来源）
- [输出契约](references/output-contract.md)（四模式 JSON Schema）
- [交互协议](references/interaction-protocol.md)（输入收集与原文来源处理）
- [鲁棒性案例](references/robustness-cases.md)（≥22 异常场景）
- [记忆结构](references/policy-schema.md)（跨会话记忆）
- [免责声明模板](references/disclaimer-template.md)（渲染强制注入）

### 2. 确定模式与收集输入

按交互协议一次性收集模式与原文来源；对比模式确认已收到 ≥2 份政策。

### 3. 读取与解析原文

- 粘贴文本 / 本地 `.txt` / `.md`：直接作为原文。
- 本地 `.docx`：调用 `python scripts/read_docx.py --input <文件>` 提取纯文本；损坏/加密/非标准则提示用户粘贴。
- `.pdf` 或其他格式：**不支持自动解析**，提示用户复制正文粘贴。
- 远程链接：不主动下载，请用户粘贴内容（避免联网与注入风险）。
- 原文读入后即为唯一事实源，不得再参考外部信息。

### 4. 模型产出结构化 JSON

按[输出契约](references/output-contract.md)对应模式的 schema 产出 JSON：**仅枚举值与文本，禁止任何分数/评分/星级/匹配度**；所有 `quote` 必须为原文逐字；`qa` 未提及问题答案置「原文未提及」且 `citations` 为空。

### 5. 校验（validate_policy.py）

```bash
python scripts/validate_policy.py --mode <mode> --input <json>
```

- `exit 0`：通过，进入渲染。
- `exit 2`：字段级错误已打印到 stderr，据此修正 JSON 后**重试，最多 2 次**。
- `exit 1`：致命（空输入/JSON 非法）；提示用户检查输入。
- 超过 2 次仍失败：降级输出已能确定的部分 + 明确人工复核提示，不抛出未处理异常。

### 6. 跨会话记忆（policy_store.py）

生成报告后记录本次解读（不可写则静默降级，不中断）：

```bash
python scripts/policy_store.py --action record --title "<标题>" --domain <领域> \
    --date <日期> --policy-hash <短哈希> --modes <mode1,mode2>
```

新会话开始时可 `python scripts/policy_store.py --action query` 获取 `recommended_focus`，用于自动建议优先关注方向。

### 7. 渲染报告（render_report.py）

```bash
python scripts/render_report.py --mode <mode> --input <json> --output report.html
# 或 Markdown 回退： --format markdown
```

脚本生成**自包含 HTML**（内联 CSS、零外链、确定性、无时间戳）或 Markdown，**强制注入免责声明与数据隐私说明**；条款引用以引用样式呈现。

### 8. 交付

向用户展示报告（HTML 预览 / Markdown），说明解读范围与局限；提醒以官方原文为准。

## 安全边界摘要

- 仅面向国内政策；不把境外机构/法案作为解读对象。
- 全程**零联网**：脚本纯标准库实现，无任何网络请求、无密钥、无 `subprocess`、无 `eval`。
- 不存储原文正文，仅存政策元信息于本机；`policy_store.py` 含路径穿越防护，越界路径自动降级。
- 报告强制注入免责声明与数据隐私说明。

## 绝对禁止

- 编造政策条款、编号、额度、日期、机关或任何原文不存在的信息。
- 将境外政策/机构作为解读对象，或在输出中出现任何境外商用大模型/平台服务名称等境外相关关键词。
- 在报告中执行或保留任何可能被解释为可执行的内容（渲染前转义所有原文/模型文本）。
- 主动下载远程链接、调用外部服务、写入密钥或将原文上传至外部。
- 在 `policy_store.py` 路径越界时强行写入；任何脚本异常未兜底即上抛导致崩溃。
