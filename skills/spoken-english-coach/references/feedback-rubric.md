# 纠错规则与评分档位（Feedback Rubric）

本文件是「纠错分类」与「评分档位」的唯一来源。模型在对话中给反馈、给 `analyze_turns.py` 打标签、给 `render_report.py` 出报告，都使用本文件的固定枚举与档位，禁止自创类别或自定分制。

## 1. 错误分类枚举（固定，脚本按此计数）

模型对每条纠错必须选且仅选一个 `category`，取值必须来自下表 `key`：

| key | 中文 | 说明 |
|-----|------|------|
| `grammar-tense` | 时态 | 现在/过去/完成/进行等误用 |
| `grammar-article` | 冠词 | a / an / the 缺失、冗余或误用 |
| `grammar-preposition` | 介词 | in / on / at / for 等搭配错误 |
| `grammar-sva` | 主谓一致 | 第三人称单数、单复数谓语不一致 |
| `grammar-plural` | 单复数 | 名词复数形式错误 |
| `grammar-word-order` | 语序 | 疑问句/从句/副词位置错乱 |
| `vocab-choice` | 用词不准 | 词意相近但语境不当 |
| `collocation` | 搭配 | 固定搭配/动宾搭配错误 |
| `chinglish` | 中式英语 | 直译母语结构、不符合英语习惯 |
| `spelling` | 拼写 | 单词拼写错误 |
| `register-tone` | 语域/语气 | 正式/口语、礼貌程度不当 |
| `fluency-filler` | 填充词过多 | um / you know / like 过度使用 |
| `fluency-repetition` | 重复单调 | 句式/词汇反复、缺乏变化 |
| `pron-hint` | 发音文本近似提示 | 音近词混淆（如 ship/sheep）；仅为文本近似提示，非真实发音评测 |
| `other` | 其他 | 无法归入上述类别时（尽量少用） |

> 约束：同一句话的多个问题，每条单独成条并各自带 `category`；不要合并。模型只做「分类 + 改写 + 一句为什么」，不计算任何计数或分数——计数与分数由 `analyze_turns.py` 确定性产出。

## 2. 纠错风格（微反馈）

- **鼓励式、不打击**：先肯定可取之处，再给修正。
- **不改写原意**：只修正语言形式，绝不替用户改变想表达的意思。
- **结构固定**：每条反馈给四要素——
  1. `issue`：一句话指出问题（用类别名，如「时态」）。
  2. `your_phrase`：逐字引用用户原句/原短语。
  3. `better`：更自然/正确的版本。
  4. `why`：一句中文或英文解释（≤ 25 词）。
- **轮次上限**：每轮最多给 **3 条**优先纠错，按「影响理解 > 高频 > 低级」排序；其余留到报告。
- **不整句翻译**：用户要「帮我把这句翻译成中文/英文整句」时，只给提示与关键词，引导其自己表达（见 robustness-cases）。
- **语言**：纠错说明默认中文（面向中文用户），`better` 用英文。

## 3. 评分档位（定性，定量公式在 analyze_turns.py）

`analyze_turns.py` 依据错误密度与词汇多样性输出 0–100 的 `band_score` 并映射到档位：

| band | 分数区间 | 含义 |
|------|----------|------|
| A | 90–100 | 流利准确，偶有瑕疵 |
| B | 75–89 | 能顺畅沟通，局部需打磨 |
| C | 60–74 | 可理解，但错误影响表达 |
| D | 40–59 | 基础薄弱，多处影响理解 |
| E | 0–39 | 起步阶段，需大量支持 |

- 档位仅反映**当次练习的语言表现**，不评价用户本人能力，不用于任何正式考试判定。
- 报告中须注明：此为练习反馈，非专业语言测评。

## 4. 难度自适应信号（供交互协议使用）

`analyze_turns.py` 额外输出 `difficulty_adjustment`：`up`（近期干净，可加难）/ `down`（近期错误密集，应降难）/ `steady`。模型据此在下一轮调整陪练句复杂度（见 interaction-protocol.md §3）。
